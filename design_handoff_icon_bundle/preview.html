How it themes
One prop, no forked SVGs.
Each icon renders in currentColor. In the mobile app, wrap the set in a component that reads the existing useColors() hook and passes colors.text as the color prop by default — light/dark/system inherits automatically because ThemeProvider already tracks Appearance.
// mobile/components/Icon.tsx
export function Icon({ name, size = 22, color }: Props) {
  const c = useColors();
  const stroke = color ?? c.text;
  return <Svg width={size} height={size} viewBox="0 0 24 24"
    stroke={stroke} fill="none" strokeWidth={1.5}>
    {PATHS[name]}
  </Svg>;
}
Drawing rules
01
24×24 grid, 2px keyline
Every glyph sits in a 20×20 inner square. Nothing touches the edge.
02
1.5px stroke, round caps & joins
Same weight across the set so Holdings and Settings don't fight.
03
Two exceptions can carry colour
trade.buy / trend.up use positive. trade.sell / trend.down / delete use negative. Nothing else.
04
Hover / press → accent
Interactive icons swap to colors.accent on press (hover this preview to see it).
